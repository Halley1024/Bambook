**本次新挖出、后续可复用的核心技术事实（此前几轮都没读到这一层）**：
- **`fz_context` 是 thread-local**：`native/mupdf-rs/src/context.rs` 用 `thread_local! { static LOCAL_CONTEXT }`，`Context::get()` 缺则从 `BASE_CONTEXT` 克隆。→ 这才是「每 session 一个专属 worker 线程」的**真正原因**（Document 只能在创建它的线程用）；`Mutex<Document>` 只保证互斥、不保证同线程，是错的。这条把第 2 节的因果链闭合了。
- **longjmp 闭合位置**：`native/mupdf-sys/wrapper/internal.h` 的 `TRY_CATCH(ty, init, call)` 宏把 `fz_try{result=call;}fz_catch{mupdf_save_error(ctx,errptr);}return result;` 包在**同一个 C 函数帧**内；`wrapper/error.c::mupdf_save_error` 用 `fz_caught(ctx)`/`fz_caught_message(ctx)` 取 type+message 并 `malloc`+`strdup` 写进 out-param；Rust `error.rs::ffi_try!` 用 `NonNull::new(err).map_or(Ok(res), Err)` 翻译，并在 `ffi_error` 里调 `mupdf_drop_error` 释放跨语言堆内存。**示例函数** `wrapper/document.c::mupdf_open_document`。
- **原子写完整参数**：`infrastructure/filesystem/atomic_file.rs` —— 同目录临时名 `.名字.<pid>-<NEXT_TEMP_FILE>.tmp` + `create_new(true)`（最多重试 16 次）+ 写完后 `OpenOptions::write(true).open()?.sync_all()` + `MoveFileExW(REPLACE_EXISTING | WRITE_THROUGH)`；非 Windows 走 `fs::rename` 后**再 fsync 父目录**；`TemporaryFileGuard`（Drop 删临时文件）+ 成功后 `disarm()`。测试 `failed_generation_keeps_the_existing_destination` 验证失败后目标不变且目录只剩 1 个文件。
- **导出后回读校验**：`infrastructure/markdown/exporter.rs` —— HTML 校验 `starts_with(b"<!doctype html>") && ends_with(b"</html>")`；PDF 用 `Document::open` 重开并校验 `page_count() > 0`，不合格返回 `InvalidExportOutput` 从而回滚。HTML→PDF 路径 = pulldown-cmark 出 HTML → `mupdf::Document::from_bytes(html, "text/html")` → `layout(595.0, 842.0, 12.0)` → `convert_to_pdf(0,-1,0)` → `pdf.save()`。**这就是 MuPDF 换不掉的原因之一。**
- **normalizer 细节**：软连字符 `U+00AD` 直接 `continue` 跳过（不产生 unit）；跨行连字符折叠需**前后非空白字符都是字母数字**；NFKC → lowercase（非 case_sensitive）→ 空白折叠（结果串已以空格结尾则跳过）；每个归一化字符一条 `NormalizedUnit{normalized_*, source_*, line, rect}`。
- **搜索矩形合并**：`search_index.rs::merge_rects` 同 line + 垂直重叠 > `min(height)*0.5` + 水平间距 ≤ `max(height)*0.8` 才合并。`context()` 用 `char_indices().rev().nth(radius)` **按字符不按字节**截取（有测试守 UTF-8 边界）。
- **`PdfDocumentService::render_page` 校验 `scale ∈ [0.25, 5.0]`**，超出返回 `PageOutOfRange`；服务还维护 `managed_documents: Mutex<HashMap>` ↔ `storage.prepare_pdf/persist_pdf`。
- **前端文字层分 run 规则**（`PdfTextLayer.tsx`）：当前 run ≥8 字符、或间距 > `max(3, fontSize*0.75)`、或字号差 > `max(1, fontSize*0.2)` 就断新 run；`characters[].rect` 会额外 ÷ `structure.width/height` 转 0..1 供选区几何用。
- **`runCloseTransaction` 在 4 处调用**（`DocumentWorkspaceProvider.tsx` 248/260/295/334）；「关闭全部/退出」会先把 preparations 存进 Map 再传一个覆盖版 prepare，**避免阶段 B 重新查 tabs 导致提交对象错位**。
- `LruCache.trim()` 条件为 `size > maxEntries || totalWeight > maxWeight`（或关系）。
- 前端 feature 目录：annotations/documents/help/markdown/notifications/pdf/search/settings；**无 eslint 配置**（分层仅靠约定）。
