# 2026-08-07

- 通读项目 README.md、src/README.md、src-tauri/README.md，建立项目上下文：
  - Bambook 是 Tauri v2 + React 18 + TS + Rust 的 PDF 阅读 / Markdown 编辑桌面应用（当前聚焦 Windows）。
  - 核心设计：文件类型驱动工作区（不保存模式状态）；PDF/Markdown 业务隔离；React 不做可信文件访问/解析，全部走 Tauri IPC → application service → domain/port → infrastructure；第三方解析器（MuPDF 0.8、pulldown-cmark 0.13）不越过基础设施边界。
  - 数据根目录 `%LOCALAPPDATA%\Bambook`（storage 五类目录 + theme + settings/recent/closed/workspace-state JSON）。
  - 开发顺序分 11 个阶段：一~五已完成/主体完成（应用壳、统一文档工作区、PDF 渲染性能、搜索批注协议、存储基础设施）；阶段六（文档生命周期+最近文件）最近文件已后端化、关闭栈已实现；七~十一未开始（文件夹工作区、Markdown 主题导出、PDF 书签导航、PDF 批注写入保存、设置帮助发布）。
  - 待办热点：未命名 Markdown 生命周期、标签 dirty 圆点、多文档关闭事务协调器、PDF 批注交互回归验收、大型 PDF 性能验收。
- 注意：项目无 git 历史（git log 为空），log.md 为空。

## 深入代码库：开发风格与规范要点

- 前端：feature-first 组织（components/hooks/repositories/state/types/styles + index.ts 出口）；Context+Provider+custom hook 状态管理（无 Redux）；所有 IPC 经 platform/tauriClient.invokeCommand 封装到 feature repositories；discriminated union 类型（kind: "pdf"|"markdown"）；原生 CSS kebab-case，styles/index.css 聚合 @import；中文用户文案；无前端测试、无 ESLint/Prettier。
- 后端：Rust 2018 同名模块入口（无 mod.rs）；commands→application(service+port)→domain→infrastructure 四层；手写 Arc<dyn Trait> 构造器注入；AppState 集中装配（state.rs）+ bootstrap.rs 注册 command；阻塞命令统一 spawn_blocking；DTO serde camelCase + From<Domain>；AppError thiserror 枚举带路径上下文、序列化为字符串；#[cfg(test)] 内联测试 + fake port（28 文件有测试）。
- 安全规范：原子写入（临时文件+MoveFileExW+TemporaryFileGuard）、扩展名强制、生成文件重新打开校验。
- 版本：Tauri 2.7 / React 18.3 / TS 5.7 strict / Rust 2021 / MuPDF 0.8（native/mupdf-rs）/ pulldown-cmark 0.13。

## 实现 2.2 关闭与退出（统一关闭协调器）

- 新建 `src/features/documents/close/closeCoordinator.ts`：纯逻辑 `runCloseTransaction(candidates, context)` 两阶段事务——阶段一逐个 canClose（询问前 `activateBeforeAsk` 激活对应标签），阶段二统一 release + recordClosed；任一询问返回 false 立即终止事务且无副作用。
- `DocumentWorkspaceProvider` 三个关闭入口统一走协调器：`closeDocument`（单个）/ `closeOtherDocuments`（其他）/ `prepareWindowClose`（退出），通过 `closeContext` useMemo 注入能力函数（activateBeforeAsk/canClose/release/recordClosed），协调器不依赖 ReaderDocument 类型（低耦合）。
- 需求满足：保存/不保存/取消三种决策；多文档逐个询问；询问前激活标签；取消时保留内容（阶段一无破坏性操作）；统一释放 Session。
